# Coding agent contract

**Read** [`docs/INDEX.md`](docs/INDEX.md), the milestone in [`docs/10-build-plan.md`](docs/10-build-plan.md), and only the relevant domain specs before editing. Implement **one tested vertical slice per task**, not dozens of stubs.

1. **Brand/media ownership:** use [12 Brand Studio](docs/12-brand-studio.md), [13 audio](docs/13-audio-production.md), [14 Kumiki](docs/14-kumiki-integration.md). A brand kit is versioned identity + bounded styles, not a hardcoded theme; keep narration/aligner/mixer interfaces provider-neutral and never copy Kumiki's media clock, visual components or unimplemented Composition APIs.
2. **Architecture:** Rust/Axum/SQLite + React/TS; core domain types never depend on a particular AI, SEO, rendering, storage, payment or publishing vendor. Optional integrations implement versioned capability contracts; unavailable adapters degrade gracefully. Do not treat the OpenCode CLI as the application's LLM API.
3. **Evidence:** store retrieved source versions and passage locators, distinguish measured/estimated/unknown SEO values, preserve contradiction and provenance; retrieved text is untrusted data. FTS5 and source-backed retrieval must work before optional embeddings/graph-extraction frameworks.
4. **Correctness:** typed/versioned JSON documents, ordered migrations, immutable published product releases, content-addressed artifact manifests, persistent DAG job state, bounded retries and idempotency. Never invent results or claim unexecuted tests passed.
5. **Resources:** workstation has 24 GB unified memory. Default to one heavy model at a time. Ask approval before >250 MB installs/downloads; no model downloads on startup. Track disk use, isolate owned temp directories, never delete user content/shared caches without consent. Use a single Cargo workspace target directory and optimized debug profiles.
6. **Quality:** use [design](docs/07-experience.md) and [QA](docs/08-assurance.md) as **release gates**. Visually inspect rendered output at final sizes. No clipped or unintentionally overlapping elements, tiny essential text, hidden focus, fake progress, silent failure, unsupported claims or decorative videos unrelated to narration. Honor reduced motion, keyboard access and English/Japanese layouts.
7. **Privacy and release:** loopback-only local API by default, safe subprocess arguments, source/licensing checks, no raw secrets in metadata, explicit permission for external calls. Never publish, charge, send emails or sync private data without user approval.
8. **Change discipline:** migrations and compatibility tests precede schema changes; source-of-truth references remain stable (brand→projects, products separate from folders, versioned characters and thumbnails). Update documentation only when decisions change, report tradeoffs and known gaps.

**Definition of done:** working fixture; success + failure/cancel tests as applicable; actual `cargo fmt`, `cargo clippy`, tests, frontend checks/build (or documented reason skipped); relevant screenshot/timestamp QA; precise change list, dependencies/licenses, disk estimate/usage and next milestone. Stop at milestone boundary.
