# Local tools, adoption scorecard and references

All entries are **candidates**, not implicit dependencies, verified installed software, or universal commercial rights. Before adoption inspect current repository maintenance, exact API/protocol, binaries and model weights **separately** for license, Mac M4 + 24 GB feasibility, RAM/disk, platform/codec restrictions and security. Record benchmark fixture and fallback in an architecture decision log.

| Domain | Candidate | Why evaluate / caution |
|---|---|---|
| Local text inference | [Magnitude](https://magnitude.dev/), [MLX-LM](https://github.com/ml-explore/mlx-lm), [llama.cpp](https://github.com/ggml-org/llama.cpp), [Ollama](https://github.com/ollama/ollama) | OpenAI-compatible or CLI only where **actually verified**; measure quantized output quality and peak RAM, not just token/s |
| Development coding agent | [OpenCode](https://github.com/anomalyco/opencode) | Default CLI command `opencode --model magnitude/qwen3.6-35b-a3b:gguf:q2` is **for coding**, not application inference protocol |
| SEO/owned search | [OpenSEO](https://github.com/every-app/open-seo), [Search Console](https://developers.google.com/webmaster-tools), [DataForSEO](https://dataforseo.com/) | Scope/provider/cost/date coverage; OpenSEO software may be free but underlying data is often paid |
| Graph/RAG | [Cognee](https://github.com/topoteretes/cognee), [Graphiti](https://github.com/getzep/graphiti), [LightRAG](https://github.com/HKUDS/LightRAG), [petgraph](https://github.com/petgraph/petgraph) | Test actual quality vs SQLite+FTS; graph frameworks are optional extraction/retrieval adapters, not authoritative store |
| Local semantic index | [sqlite-vec](https://github.com/asg017/sqlite-vec), [fastembed-rs](https://github.com/Anush008/fastembed-rs) | Embedding compatibility/version and optional download; FTS5 must work without it |
| SVG/layout | [resvg](https://github.com/linebender/resvg), [ELK.js](https://github.com/kieler/elkjs), [Satori](https://github.com/vercel/satori), [Playwright](https://playwright.dev/) | Typed layout and actual rendered-text geometry, maintain editability |
| Image illustration | [MFLUX](https://github.com/mflux-community/mflux), FLUX.2 Klein 4B, Z-Image | Verify **individual weight** license before commercial outputs; quantized model and scratch memory fit |
| Kumiki composition | [Kumiki-UI](https://github.com/YukiUmetsu/kumiki-ui) source registry and local VideoExportStage/FFmpeg | Prefer existing media/motion/infographic/visual safeguards; do not use unimplemented Composition APIs or assume npm package delivery |
| Fish Audio cloud narration | [Fish Audio](https://fish.audio/) developer API | Candidate only; verify endpoint/model support, usage limits, exact current monetized-output terms and voice rights; no cloud calls before grant |
| Local/imported narration | Qwen3-TTS MLX, Kokoro, imported WAV | Alternate speech providers behind one logical VoiceProfile, not hardcoded model IDs |
| Sound/music processing | FFmpeg, per-item rights-checked SFX/music assets, optional offline aligner | ContentGen owns multi-lane mix/master; no copyrighted sample bundles assumed |
| Video animation | [Motion Canvas](https://github.com/motion-canvas/motion-canvas), [HyperFrames](https://github.com/heygen-com/hyperframes), [Remotion](https://github.com/remotion-dev/remotion) | Prefer deterministic scene rendering; Remotion has distinct commercial licensing conditions; adapters only |
| Audio/transcription | [Qwen3-TTS MLX](https://github.com/syedpeer/qwen3-tts-mlx), [Kokoro](https://github.com/hexgrad/kokoro), [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [Rhubarb](https://github.com/DanielSWolf/rhubarb-lip-sync) | Language/voice and trained-weight rights; Rhubarb English-oriented; measure Japanese alignment |
| Characters | [Inochi2D](https://github.com/Inochi2D/inochi2d), [Blender](https://www.blender.org/), [MPFB2](https://github.com/makehumancommunity/mpfb2) | Start with layered sprites; mature rig creation costs; separate software and generated asset rights |
| Record/demos | [OBS](https://github.com/obsproject/obs-studio), [Playwright](https://playwright.dev/), [auto-editor](https://github.com/WyattBlue/auto-editor) | Record real operations; redact secrets; deterministic assertions required |
| UI/QA | React, [Base UI](https://base-ui.com/), [React Aria](https://react-aria.adobe.com/), optional [Kumiki UI](https://github.com/shadcn-ui/ui) registry pattern, [Storybook](https://storybook.js.org/), [axe-core](https://github.com/dequelabs/axe-core) | Accessibility, styling independence, responsive/Japanese visual tests, no required shared repo |
| Interactive learning | [H5P](https://h5p.org/), custom JSON exercises | Validate answer keys and license; export optionally |
| Provenance | [c2pa-rs](https://github.com/contentauth/c2pa-rs) | Optional signed production claims; not a guarantee of truth/ownership |

**Adapter scoring (0–5 each):** content accuracy, output quality, API stability, license clarity, local RAM/disk feasibility, execution speed, debugging/reproducibility, maintenance; log measured evidence, not unsupported rankings. Benchmark identical small research+article, infographic, ~30–45s video, thumbnail and TTS fixtures. Run on target 24GB machine and capture peak resident memory, disk, time, errors, editorial corrections and usable artifacts/hour. Avoid unnecessary parallel heavy models.

**Never automatically install:** image/video weights, a graph server, Docker images, codecs, FFmpeg binaries or large language-model variants. Request permission before substantial downloads; keep a zero-cloud, text/FTS5/manual-SVG path. Export failures and provider limitations should be shown as constraints, not hidden by a substitute model or sample output.
